# Day 1 — Network Basics 🌐

## 1. What is a Network?

A **network** is a group of two or more devices connected so that they can communicate and share data or resources.

Examples of devices on a network:

* Laptop
* Smartphone
* Printer
* Smart TV
* Server

### Example

At home, a laptop and phone may both connect to the same Wi-Fi router.

```text
Laptop ──┐
         ├── Wi-Fi Router
Phone  ──┘
```

These devices are part of a local network.

A network does **not necessarily require Internet access**. Devices on the same local network may still be able to communicate or share resources even when the Internet connection is unavailable.

---

# 2. What is the Internet?

The **Internet** is a huge global system of interconnected networks.

A simplified communication path looks like:

```text
My Device
    ↓
Router
    ↓
ISP
    ↓
Internet
    ↓
Destination Server
```

For example, when a laptop accesses a website, data may travel through the local router and ISP before being routed across the Internet toward the destination server.

### Network vs Internet

| Network                   | Internet                     |
| ------------------------- | ---------------------------- |
| Connects devices/networks | Connects networks globally   |
| Can be local              | Worldwide                    |
| Can work without Internet | Provides global connectivity |
| Example: home network     | Example: the global Internet |

**Important:** A network and the Internet are not the same thing.

---

# 3. LAN — Local Area Network

**LAN = Local Area Network**

A LAN covers a relatively small geographical area.

Examples:

* Home network
* School computer lab
* Office network

Example:

```text
Laptop ──┐
Phone  ──┼── Router
Printer ─┘
```

These devices can be part of the same LAN.

### Key Point

**LAN = Local = Small Area**

---

# 4. WAN — Wide Area Network

**WAN = Wide Area Network**

A WAN connects devices or networks across a much larger geographical area.

For example, a company may connect networks in offices located in different cities.

```text
Office Network — Jaipur
        │
        │   WAN
        │
Office Network — Delhi
```

The Internet can be thought of as the world's largest example of interconnected wide-area networking.

### LAN vs WAN

| LAN                       | WAN                                    |
| ------------------------- | -------------------------------------- |
| Local Area Network        | Wide Area Network                      |
| Smaller geographical area | Larger geographical area               |
| Home, school, office      | Cities, regions, countries             |
| Usually locally managed   | May connect multiple separate networks |

---

# 5. What is a Router?

A **router** is a networking device that forwards packets between different networks.

Its job is to determine where network traffic should be sent next.

In a typical home setup:

```text
Laptop ──┐
Phone  ──┼── Router ── ISP ── Internet
TV     ──┘
```

The router connects the home network to other networks, commonly through an ISP.

### Simple Definition

**Router = A device that forwards traffic between networks.**

---

# 6. What is an ISP?

**ISP = Internet Service Provider**

An ISP is a company or organization that provides Internet connectivity to customers.

A simplified path is:

```text
Device
   ↓
Router
   ↓
ISP
   ↓
Internet
```

The router and ISP have different jobs:

* **Router:** Forwards network traffic between networks.
* **ISP:** Provides connectivity to the wider Internet.

---

# 7. How Everything Connects

Suppose I open a website on my laptop.

At a very basic level, the communication path can be visualized as:

```text
My Laptop
    ↓
Home Router
    ↓
ISP
    ↓
Internet
    ↓
Website Server
```

The server's response is then routed back toward my device.

This diagram is intentionally simplified. Concepts such as IP addresses, DNS, NAT, TCP/UDP, and HTTP/HTTPS explain what happens in more detail.

# 8. Practical — Explore My Network Safely 💻

These commands can be run on my own Windows PC using **Command Prompt (CMD)**.

## Practical 1 — View Network Configuration

Open Command Prompt and run:

```cmd
ipconfig
```

This displays information about the computer's network adapters.

Some important fields to look for are:

```text
IPv4 Address
Subnet Mask
Default Gateway
```

At this stage, the goal is simply to recognize that the computer has network configuration information. IP addresses, subnet masks, and gateways are covered in later lessons.

---

## Practical 2 — Test My Own Computer

Run:

```cmd
ping 127.0.0.1
```

`127.0.0.1` is an IPv4 **loopback address**.

It refers back to the local computer's networking stack.

Example successful output may contain:

```text
Reply from 127.0.0.1
```

This is a basic way to test the local TCP/IP networking stack.

---

## Practical 3 — Identify the Default Gateway

Run:

```cmd
ipconfig
```

Find:

```text
Default Gateway
```

In a typical home network, the IPv4 default gateway is usually the local address of the router.

Conceptually:

```text
My Computer
     ↓
Default Gateway / Router
     ↓
Other Networks
```

Do not change any router or network settings for this exercise. The goal is only to observe the configuration.

---

## Practical 4 — Ping My Own Local Gateway

After identifying the local default gateway on my own network, I can test whether it responds to ping.

Example:

```cmd
ping <my-default-gateway>
```

If the gateway is reachable and configured to respond to ping, replies may appear.

A lack of ping replies does **not always mean the device or network is broken**, because devices can be configured not to answer ping requests.

# 9. Important Terms

| Term     | Meaning                                                |
| -------- | ------------------------------------------------------ |
| Network  | Connected devices that can communicate/share resources |
| Internet | Global system of interconnected networks               |
| LAN      | Local Area Network                                     |

| Router   | Forwards packets between networks                      |
| ISP      | Internet Service Provider                              |
| Packet   | A unit of data transmitted across a network            |
